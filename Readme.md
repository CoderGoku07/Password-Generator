# Password Generator

## Project Overview
A Python-based application that generates random passwords according
to the user's selected length and character requirements.

## Features
- Custom password length
- Uppercase letters
- Lowercase letters
- Numbers
- Special characters
- Input validation
- Random password generation

## Technologies Used
- Python
- random/secrets
- string

## How to Run
1. Install Python.
2. Download or clone the repository.
3. Open the project folder.
4. Run:

python password_generator.py

## How It Works
The program collects the user's requirements, creates a pool of
allowed characters, randomly selects characters, and displays the
generated password.
