Password Generator


Project Statement

The Password Generator is a simple Python-based program that generates random and secure 
passwords according to the user's requirements.
The user can enter the desired password length and choose whether to include:
Capital letters (A-Z)
Small letters (a-z)
Numbers (0-9)
Special characters (!, @, #, $, etc.)
The program uses Python's 
random and 
string modules to create the password. It 
randomly selects characters from the options chosen by the user and generates a password of 
the required length.


Objective

The main objective of this project is to create a simple password generator that helps users 
generate strong and random passwords easily.


Features

1. User can select the password length.
2. User can choose capital letters.
3. User can choose small letters.
4. User can choose numbers.
5. User can choose special characters.
6. The password is generated randomly.
7. The program checks that at least one character option is selected.
8. The program displays the generated password to the user.


Technologies Used

Python
Random module
String module


Input

The program takes the following inputs from the user:
Password length
Capital letters: Yes/No
Small letters: Yes/No
Numbers: Yes/No
Special characters: Yes/No


Output

The program generates and displays a random password based on the user's selected options.


Example

Enter password length: 10
Include capital letters (A-Z)? Yes/No: Yes
Include small letters (a-z)? Yes/No: Yes
Include numbers (0-9)? Yes/No: Yes
Include special characters (!@#$)? Yes/No: Yes
Your password is:
G7@kp2!Xq9


Conclusion

This project demonstrates how Python can be used to create a useful password generator 
using basic programming concepts such as user input, conditions, loops, strings, and random 
selection.
